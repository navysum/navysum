### Cybersecurity · AI Systems · Automation · Software Engineering

I build practical systems around **cybersecurity, AI agents, automation, infrastructure, and data**.

A lot of my work focuses on connecting different tools and services into systems that can actually run continuously — from personal AI infrastructure and dashboards to security tooling and quantitative research.
