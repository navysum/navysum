# Hi, I'm Craig 👋

### Computer Science Student | Cybersecurity | Automation | AI Systems

I'm a Computer Science student at **City, University of London**, focused on cybersecurity, defensive security, automation, and practical software engineering.

I build tools that solve real problems: security utilities, automation systems, trading research tools, dashboards, and agentic workflows. My main interest is where **cybersecurity, AI, infrastructure, and data-driven decision making** overlap.

Currently onboarding with the **National Cyber Resilience Centre Group** through the **Cyber PATH** programme.
